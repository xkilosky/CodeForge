# File type icons

These SVGs are official file icons from the [VSCode Icons](https://github.com/vscode-icons/vscode-icons) icon set, distributed in Iconify's `@iconify-json/vscode-icons` 1.2.96 package. They are used in the project file explorer and remain separate SVG assets so the original vector artwork and colors are preserved.
